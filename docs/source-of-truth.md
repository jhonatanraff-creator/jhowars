# Fonte de verdade do novo Jhow.ars

## Site legado

O Adobe Portfolio salvo é fonte histórica de conteúdo, textos, assets, projetos, obras, URLs e informações antigas. Use os inventários de `docs/legacy/`; mantenha a redação literal até receber instrução de edição.

O site legado não define a nova interface, Design System, grid, tipografia ou arquitetura visual. O HTML antigo não é referência para reconstruir páginas.

## Novo Figma

Quando fornecido e aprovado, o Figma é a fonte de verdade para composição visual, grid, tipografia, espaçamento, hierarquia, responsive, componentes e comportamento visual.

## Conflitos

- Conteúdo → inventário / legado aprovado.
- Visual → Figma aprovado.
- Nunca simplificar o Figma para se adaptar ao HTML antigo.
